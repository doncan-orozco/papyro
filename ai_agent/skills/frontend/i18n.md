# I18n Skill (English + Spanish)

**Reference: [VERIFICATION_CHECKLIST.md](../../VERIFICATION_CHECKLIST.md#-internationalization-i18n)**

This skill provides implementation details for I18n. For complete guidelines, see the verification checklist.

## Dependencies
- i18n (Rails default)

## File Structure

```
config/locales/
  en/
    app.yml
    articles.yml
    games.yml
    components.yml
    models.yml
    errors.yml
  es/
    app.yml
    articles.yml
    games.yml
    components.yml
    models.yml
    errors.yml
```

## Rules
- **Views** use domain files: `articles.yml`, `games.yml`.
- **Components** use `components.yml`.
- **Shared UI** uses `app.yml`.
- **Models/attributes/enums** use `models.yml`.
- Avoid large single locale files; keep domains split.

## View Keys (Scoped)

Prefer scoped keys in views:

```ruby
# app/views/articles/index.rb
h1 { t(".title") }
```

```yaml
# config/locales/en/articles.yml
en:
  articles:
    index:
      title: "Articles"
```

## Component Keys

Use component namespace:

```ruby
render Components::Ui::Button.new { t("components.button.primary") }
```

```yaml
# config/locales/en/components.yml
en:
  components:
    button:
      primary: "Save"
```

## Model Attributes + Enums

```yaml
# config/locales/en/models.yml
en:
  activerecord:
    models:
      article: "Article"
    attributes:
      article:
        title: "Title"
        status: "Status"
    enum:
      article:
        status:
          draft: "Draft"
          published: "Published"
```

Use in code:

```ruby
Article.human_attribute_name(:title)
Article.human_enum_name(:status, :draft)
```

## Spanish Example

```yaml
# config/locales/es/articles.yml
es:
  articles:
    index:
      title: "Artículos"
```

## Date/Time Formats

```yaml
# config/locales/en/app.yml
en:
  time:
    formats:
      short: "%b %-d, %Y"
      long: "%B %-d, %Y"
  date:
    formats:
      short: "%b %-d, %Y"
      long: "%B %-d, %Y"
```

```yaml
# config/locales/es/app.yml
es:
  time:
    formats:
      short: "%-d %b %Y"
      long: "%-d de %B de %Y"
  date:
    formats:
      short: "%-d %b %Y"
      long: "%-d de %B de %Y"
```

## Number/Currency Formats

```yaml
# config/locales/en/app.yml
en:
  number:
    format:
      delimiter: ","
      separator: "."
    currency:
      format:
        unit: "$"
        format: "%u%n"
```

```yaml
# config/locales/es/app.yml
es:
  number:
    format:
      delimiter: "."
      separator: ","
    currency:
      format:
        unit: "€"
        format: "%n %u"
```

## Fallbacks

Enable fallbacks so missing keys fall back to English:

```ruby
# config/application.rb
config.i18n.available_locales = %i[en es]
config.i18n.default_locale = :en
config.i18n.fallbacks = [:en]
```
