# I18n Examples (English + Spanish)

**For complete guidelines, see: [ai_agent/VERIFICATION_CHECKLIST.md](../VERIFICATION_CHECKLIST.md#-internationalization-i18n)**

Recommended structure for translations and key naming:

```
config/locales/
  en/
    app.yml
    articles.yml
    games.yml
    components.yml
    models.yml
    errors.yml
  es/
    app.yml
    articles.yml
    games.yml
    components.yml
    models.yml
    errors.yml
```

## Scoped View Translation

```ruby
# app/views/articles/index.rb
h1 { t(".title") }
```

```yaml
# config/locales/en/articles.yml
en:
  articles:
    index:
      title: "Articles"
```

```yaml
# config/locales/es/articles.yml
es:
  articles:
    index:
      title: "Artículos"
```

## Component Translation

```ruby
render Components::Ui::Button.new { t("components.button.primary") }
```

```yaml
# config/locales/en/components.yml
en:
  components:
    button:
      primary: "Save"
```

```yaml
# config/locales/es/components.yml
es:
  components:
    button:
      primary: "Guardar"
```

## Model Attributes + Enums

```yaml
# config/locales/en/models.yml
en:
  activerecord:
    models:
      article: "Article"
    attributes:
      article:
        title: "Title"
        status: "Status"
    enum:
      article:
        status:
          draft: "Draft"
          published: "Published"
```
```ruby
Article.human_attribute_name(:title)
Article.human_enum_name(:status, :draft)
```

## Date/Time Formats

```yaml
# config/locales/en/app.yml
en:
  time:
    formats:
      short: "%b %-d, %Y"
      long: "%B %-d, %Y"
  date:
    formats:
      short: "%b %-d, %Y"
      long: "%B %-d, %Y"
```

```yaml
# config/locales/es/app.yml
es:
  time:
    formats:
      short: "%-d %b %Y"
      long: "%-d de %B de %Y"
  date:
    formats:
      short: "%-d %b %Y"
      long: "%-d de %B de %Y"
```

## Number/Currency Formats

```yaml
# config/locales/en/app.yml
```
  number:
    format:
      delimiter: ","
      separator: "."
    currency:
      format:
        unit: "$"
        format: "%u%n"
```

```yaml
# config/locales/es/app.yml
es:
  number:
    format:
      delimiter: "."
      separator: ","
    currency:
      format:
        unit: "€"
        format: "%n %u"
```

## Fallbacks

```ruby
# config/application.rb
config.i18n.available_locales = %i[en es]
config.i18n.default_locale = :en
config.i18n.fallbacks = [:en]
```
