# I18n Examples (English + Spanish)

**For complete guidelines, see: [skills/frontend/i18n.md](../skills/frontend/i18n.md)**

**Key Principle**: Always use fully-qualified translation keys (NO relative keys like `t(".title")`).

## File Structure

```
config/locales/
  en/
    app.yml          # Shared: date/time/number formats, common UI
    articles.yml     # Articles: views + operations + errors
    users.yml        # Users domain
    components.yml   # Reusable components
    models.yml       # ActiveRecord translations
  es/
    app.yml
    articles.yml
    users.yml
    components.yml
    models.yml
```

---

## View Translation (Fully-Qualified Keys)

**❌ DON'T:**
```ruby
# WRONG - Relative key
h1 { t(".title") }
```

**✅ DO:**
```ruby
# app/views/articles/index.rb
class Articles::Index < Views::Base
  def view_template
    h1 { t("articles.index.title") }  # Explicit, grep-able
    p { t("articles.index.description") }
  end
end
```

```yaml
# config/locales/en/articles.yml
en:
  articles:
    index:
      title: "All Articles"
      description: "Browse all published articles"
```

```yaml
# config/locales/es/articles.yml
es:
  articles:
    index:
      title: "Todos los artículos"
      description: "Explorar todos los artículos publicados"
```

## Operation Messages (Domain-Scoped)

```ruby
# app/controllers/articles_controller.rb
def create
  result = Articles::Operation::Create.call(params: params.to_unsafe_h)
  
  if result.success?
    redirect_to articles_path, notice: I18n.t("articles.operations.create.success")
  else
    flash.now[:alert] = I18n.t("articles.operations.create.failure")
    render :new
  end
end
```

```yaml
# config/locales/en/articles.yml
en:
  articles:
    operations:
      create:
        success: "Article created successfully"
        failure: "Failed to create article"
      update:
        success: "Article updated successfully"
      destroy:
        success: "Article deleted successfully"
```

```yaml
# config/locales/es/articles.yml
es:
  articles:
    operations:
      create:
        success: "Artículo creado exitosamente"
        failure: "Error al crear artículo"
      update:
        success: "Artículo actualizado exitosamente"
      destroy:
        success: "Artículo eliminado exitosamente"
```

## Error Messages (Domain-Scoped)

```ruby
# app/concepts/articles/contract/create.rb
module Articles
  module Contract
    class Create < Reform::Form
      property :title
      property :body
      
      validation do
        required(:title).filled(:str, min_size?: 3)
        required(:body).filled(:str)
      end
    end
  end
end

# app/concepts/articles/operation/create.rb
def validate(ctx, params:, **)
  contract = Articles::Contract::Create.new(Article.new)
  
  if contract.validate(params[:article])
    ctx[:model] = contract.model
    true
  else
    ctx[:errors] = {
      title: [I18n.t("articles.errors.title_blank")],
      body: [I18n.t("articles.errors.body_blank")]
    }
    false
  end
end
```

```yaml
# config/locales/en/articles.yml
en:
  articles:
    errors:
      title_blank: "Article title cannot be blank"
      title_too_short: "Article title must be at least 3 characters"
      body_blank: "Content is required"
```

```yaml
# config/locales/es/articles.yml
es:
  articles:
    errors:
      title_blank: "El título del artículo no puede estar vacío"
      title_too_short: "El título debe tener al menos 3 caracteres"
      body_blank: "El contenido es obligatorio"
```

## Date/Time Formatting (Use I18n.l, NOT strftime)

**❌ DON'T:**
```ruby
# WRONG - Hardcoded format, no localization
div { article.published_at.strftime("%B %-d, %Y") }
```

**✅ DO:**
```ruby
# CORRECT - Use I18n.l (localize)
class Articles::Show < Views::Base
  def view_template
    div(class: "metadata") do
      p { I18n.l(@article.published_at, format: :long) }
      p { I18n.l(@article.updated_at.to_date, format: :short) }
      p { I18n.l(@article.created_at, format: :time_only) }
    end
  end
end
```

```yaml
# config/locales/en/app.yml
en:
  date:
    formats:
      default: "%Y-%m-%d"
      short: "%b %-d"
      long: "%B %-d, %Y"
  time:
    formats:
      default: "%a, %d %b %Y %H:%M:%S %z"
      short: "%d %b %H:%M"
      long: "%B %-d, %Y %H:%M"
      time_only: "%H:%M"
```

```yaml
# config/locales/es/app.yml
es:
  date:
    formats:
      default: "%Y-%m-%d"
      short: "%-d %b"
      long: "%-d de %B de %Y"
  time:
    formats:
      default: "%a, %d %b %Y %H:%M:%S %z"
      short: "%-d %b %H:%M"
      long: "%-d de %B de %Y %H:%M"
      time_only: "%H:%M"
```

**Result:**
- English: "February 10, 2026"
- Spanish: "10 de febrero de 2026"

## Number/Currency Formatting

**❌ DON'T:**
```ruby
# WRONG - Manual formatting
span { "$#{article.price.round(2)}" }
span { "Views: #{article.views}" }
```

**✅ DO:**
```ruby
# CORRECT - Use number helpers
class Articles::Show < Views::Base
  def view_template
    div do
      span { number_to_currency(@article.price) }
      span { "#{number_with_delimiter(@article.views)} views" }
      span { number_to_percentage(@article.completion_rate, precision: 1) }
    end
  end
end
```

```yaml
# config/locales/en/app.yml
en:
  number:
    format:
      delimiter: ","
      separator: "."
    currency:
      format:
        unit: "$"
        format: "%u%n"
```

```yaml
# config/locales/es/app.yml
es:
  number:
    format:
      delimiter: "."
      separator: ","
    currency:
      format:
        unit: "€"
        format: "%n %u"
```

**Result:**
- English: "$1,234.56" and "1,234,567 views"
- Spanish: "€1.234,56" and "1.234.567 vistas"

## Best Practices

1. ✅ **Always fully-qualified keys**: `t("articles.show.title")` not `t(".title")`
2. ✅ **Domain-scope errors**: `articles.errors.title_blank` for context
3. ✅ **Use I18n.l for dates**: Never `strftime`
4. ✅ **Use number helpers**: `number_to_currency`, `number_with_delimiter`
5. ✅ **Both languages**: English + Spanish required
6. ✅ **Organize by domain**: All article translations in `articles.yml`
7. ✅ **Operations under `.operations`**: Clear namespace
8. ✅ **No hardcoded text**: Everything user-facing needs i18n

For complete patterns, see [skills/frontend/i18n.md](../skills/frontend/i18n.md)
